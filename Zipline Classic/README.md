# Zipline Classic

Legacy-compatible SwiftUI edition. Minimum deployment target: iOS 15; supports iPhone 6s. Open `Zipline Classic.xcodeproj` directly in Xcode.
\n## Puzzle rules\n\nDraw one continuous path from 1, pass every checkpoint in order, and visit every cell exactly once. Thick borders between adjacent cells are walls; the path cannot cross them. Drag backwards or use Undo to backtrack. Hint rewinds an incorrect branch and highlights the correct route to the next checkpoint.\n
