# Zipline

A little path. A lot of logic. The native SwiftUI puzzle game by Amirali Yazdani.

Two separate editions: **Zipline Main** (iOS 17+) and **Zipline Classic** (iOS 15+, including iPhone 6s). The main app uses native Liquid Glass on iOS 26+ with graceful system-material fallbacks; Classic intentionally retains the iOS 15-compatible interface.

See the complete source, build instructions, edition comparison, and CI details in this README. The full application source is being published in the initial project commit.
